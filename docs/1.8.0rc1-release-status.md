# 1.8.0rc1 release status

This candidate is being prepared and is not yet published. Stable 1.7.1 remains
the recommended release.

The candidate adds shared column semantics and privacy guards, exact bounded
CSV distinct counting with an optional `profiling` DuckDB/Arrow extra, and
explicit `tiled-v1` / `generate --stream-csv` generation. It also improves CSV
validation and exact numeric calculations. Existing 1.7.1 DECIMAL, rules,
relationships, scenarios and scalable execution engines remain available;
streaming is opt-in and uses a separate deterministic seed stream. See the
[parallel/streaming guide](how-to/parallel-generation.md),
[profiling reference](reference/profiling.md) and
[changelog](https://github.com/wa-pis/agent-paranoid-android/blob/main/CHANGELOG.md).

Folder caches advance to format 12 and SQL query-source policy to 1.2. Reprofile
saved source artifacts and review the resulting specification. Existing source
authorization, scan/work budgets and transformation approval boundaries remain
in force; this release does not approve a dataset or activate a new
transformation extension.

Before publication, qualify the exact main commit with the full release gate,
strict documentation, CI/Containers/Documentation/Security workflows,
independent exact-source review, installed-artifact fictional checks and Ubuntu
no-publish artifact hashes. Prior source checks and benchmark evidence keep
their recorded source identity and do not replace candidate acceptance.
Bind the accepted source and artifact hashes in the signed release manifest;
verify GitHub, PyPI and all three GHCR artifacts after publication. Candidate
documentation belongs at `versions/1.8.0rc1/`; keep the stable documentation
catalog and default at publicly verified 1.7.1.
