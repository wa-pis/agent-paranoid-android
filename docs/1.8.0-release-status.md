# 1.8.0 release status

Stable 1.8.0 is published and its packages and three signed images are publicly verified.
See [release evidence](release-evidence-1.8.0.md) for exact stable-source gates,
independent reviews, installed acceptance and public package/image verification.

This release promotes the runtime of the
[publicly verified 1.8.0rc1 candidate](release-evidence-1.8.0rc1.md), changing
only version metadata and release documentation. Candidate acceptance and
historical benchmarks retain their original source and artifact identities.

The documentation revision and full-scope public verification are tracked
separately; artifacts-only verification does not establish live guide acceptance.
Publication grants no dataset approval or new transformation activation, and
the separate human-review task remains open.
