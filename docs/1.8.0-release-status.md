# 1.8.0 release status

Stable 1.8.0 is being prepared. Until publication and public artifact
verification, the last publicly available stable release remains 1.7.1.

This promotion retains the runtime of the
[publicly verified 1.8.0rc1 candidate](release-evidence-1.8.0rc1.md), changing
only version metadata and release documentation. Candidate acceptance and
historical benchmarks retain their original source and artifact identities.

The final stable source requires fresh exact-commit gates, independent review,
Ubuntu artifact hashes, installed-artifact acceptance, a signed manifest and
public verification; see the [release process](release.md#180-stable-promotion).
Keep the stable documentation catalog and default at verified 1.7.1 until the
stable artifacts pass public verification. No stable publication or acceptance
is claimed here. Publication grants no dataset approval or new transformation
activation, and the separate human-review task remains open.
