# Stable 1.6.0 Release Status

**Status: authorized preparation; not yet published.** The owner requested stable
`1.6.0` on 2026-10-16 with all accepted changes since `1.5.0`. Until public
verification completes, `1.5.0` remains the recommended published stable release
and [`1.6.0rc5`](release-evidence-1.6.0rc5.md) is the publicly verified preview.
Installation examples for `1.6.0` become applicable only after that verification.

## Accepted baseline

The selected runtime is signed tag `v1.6.0rc5`, source commit
`890925afdff68e97cafe38a28605d2874c9dad79`. Main
`304e75d7f998fae6c8d58595a432880ac9da1531` adds documentation consistency fixes.
The stable promotion changes only release metadata, documentation and the
hard-coded release-version assertion. Dependencies, executable behavior,
schemas, fixtures, workflows and safety tests must remain identical to RC5.
The [release process](release.md) requires every changed hunk to satisfy that
restriction; a behavior correction requires a new accepted RC first.

The consolidated changes and migration notes are in the
[changelog](https://github.com/wa-pis/agent-paranoid-android/blob/main/CHANGELOG.md).
DatasetSpec `1.1` remains the schema version; it is independent of package `1.6.0`.
Provider adapters remain experimental. No promotion changes source-free
generation, database read-only limits or local preservation authority.
