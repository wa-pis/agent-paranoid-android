# Скачать документацию

[English](../downloads.md) · Русский

Полная опубликованная сборка содержит:

- <a href="../../downloads/handbook.pdf">PDF handbook</a> — для чтения, печати и передачи.
- <a href="../../downloads/handbook.html">Автономный HTML</a> — один файл со встроенными assets.
- <a href="../../downloads/handbook.md.zip">Markdown ZIP</a> — исходники, включая русские страницы, справочники и историю.
- <a href="../../downloads/site.zip">Offline site ZIP</a> — выбранная версия сайта с обоими языками. Распакуйте и запустите python3 -m http.server для локального поиска.

<a href="../../handbook/">Общий печатный справочник</a> включает пользовательские главы English и Русский по навигации. История, roadmap и административные страницы в него не входят. Это один двуязычный документ, а не два независимо версионируемых перевода.

Version/source пакета, documentation revision и hashes экспортов записываются в documentation.json. Исправление перевода не наследует exact-SHA review пакета. Экспорт документации не читает datasets, credentials или approvals.

Файлы появляются только после полной сборки. Обычный локальный preview содержит combined print page, но не PDF/ZIP. Порядок: [публикация документации — English](../development/documentation.md).
