# Возможности и выбор способа работы

[English](../../concepts/choosing-an-approach.md) · Русский

В таблице указаны входы, результаты и ситуации, когда функцию применять не стоит. Практическая проверка находится в соответствующей инструкции.

| Возможность | Когда использовать; вход | Результат | Когда не подходит; ограничение | Проверка |
| --- | --- | --- | --- | --- |
| Офлайн-демо | Нужно проверить установку; встроенная фикстура | 12 синтетических покупателей и отчёты | Не доказывает качество связей и бизнес-правил | [Первый запуск](../getting-started/installation.md) |
| CSV | Одна таблица; CSV с заголовком | Данные, профиль, спецификация, manifest | Не для копирования или обезличивания строк один к одному | [CSV](../getting-started/first-csv.md) |
| Папка CSV | Связанные таблицы; один файл на сущность | Профиль, предположения о связях, набор таблиц | Найденные зависимости требуют проверки; выборка ограничена | [Основной процесс](../getting-started/related-tables.md) |
| DatasetSpec | Нужен явный контракт; YAML/JSON | Управляемые строки и отчёты | Не выполняет произвольный Python, SQL или текстовые правила | [Настройка](../dataset_profile_and_spec.md) |
| Parquet-профиль | Нужны безопасные метаданные Parquet; profile-parquet | Профиль, затем reviewed spec | Неизвестные null-статистики и DECIMAL bounds требуют явного контракта | [Parquet](../reference/source-output-matrix.md) |
| Точный DECIMAL | Финансовые тесты; DatasetSpec 1.1 с decimal_range | Точные десятичные значения | FLOAT не заменяет DECIMAL; bounds задаются человеком | [DECIMAL](../reference/source-output-matrix.md) |
| Seed | Нужен повтор; спецификация и целое число ≥0 | Повторяемые данные в том же окружении | Не обещает побайтовое совпадение между версиями и платформами | [CSV](../getting-started/first-csv.md) |
| Валидация | Нужно проверить сгенерированную папку по spec | Секции schema, relationships, constraints, privacy | Не доказывает полезность и анонимность | [Валидация](../getting-started/review-output.md) |
| CSV/JSON/SQL/Parquet | Нужно передать результат тестовой системе | Файлы сущностей | Parquet требует extra; общий SQL не содержит DDL | [Форматы](../getting-started/review-output.md) |
| PostgreSQL/Trino | Разрешено читать метаданные и агрегаты | Профиль без исходных строк | Не для произвольных запросов, записи или экспорта строк | [Базы](../how-to/postgresql.md) |
| Бизнес-правила | Нужны формулы, условия, связи, сценарии | Данные и business_validation_report | Не все правила могут исправляться генератором | [Правила](../how-to/business-rules.md) |
| MCP | Нужен вызов инструментов AI-клиентом | Метаданные и пути к локальным артефактам | Ограничение workspace не заменяет изоляцию процесса | [MCP](../how-to/mcp.md) |
| AI advisor | Требуется предложение к spec по метаданным | Проверяемое предложение с повторным review | Не для отправки строк и автоматического одобрения | [AI](../ai_integration.md) |

Базовые CSV, JSON, SQL, CLI, DatasetSpec и валидация доступны без внешних сервисов. Parquet, базы, MCP и AI подключаются отдельными extras. GigaChat обозначен в коде как экспериментальный. В 1.6.0 зарегистрирована отдельная selective transformation: локальные transform-review/approve/execute, transform-batch и MCP consumers. Это mixed-origin обработка один к одному, а не синтетическая генерация; разрешение на набор и локальный receipt не выдаются агентом. См. [инструкцию](../how-to/transformation.md).
