# Agent Paranoid Android

[English](../index.md) · Русский

Agent Paranoid Android создаёт воспроизводимые синтетические тестовые данные по структуре CSV, безопасному профилю или проверенному `DatasetSpec`. Он нужен, когда важны схема, связи и бизнес-правила, а исходные строки нельзя передавать разработчикам.

Рекомендуемая стабильная версия — **1.6.0**. Её исходники, пакеты и контейнеры прошли [публичную проверку](../release-evidence-1.6.0.md). Версия сохраняет принятый runtime RC5. Перед обновлением фикстур прочитайте [изменения контракта](reference/generation-contract-migration.md).
Эта инструкция относится к кандидату `1.7.0rc1`; команды явно выбирают его.
См. [статус кандидата](../1.7.0rc1-release-status.md) перед установкой.

## Основной процесс

1. Получите структуру и ограниченные агрегаты.
2. Проверьте DatasetSpec, связи и бизнес-правила.
3. Создайте новые значения с явным seed.
4. Проверьте типы, связи, ограничения, приватность и бизнес-правила.
5. Прочитайте generation_manifest.json перед принятием набора.

Manifest синтетического набора содержит synthetic=true, source_rows_copied=false, seed и validation_valid. Эти поля не заменяют проверку самого spec и не подтверждают статистическую анонимность.

## Границы безопасности

Генерация не копирует и не перемешивает исходные строки. Внешние базы читаются только в разрешённом scope, с конечными бюджетами. Ограниченное локальное разрешение business enum не распространяется на идентификаторы, свободный текст, PII или provider payload.

Конечная fictional acceptance campaign 1.6.0 завершена с записанными ограничениями; это не одобрение пользовательского набора. Selective transformation — отдельная opt-in операция со смешанным происхождением результата. Она не является синтетической генерацией. Сохранение ячеек требует local receipt от человека; регистрация CLI/MCP не одобряет набор. См. [workflow](reference/cli-workflows.md) и [модель безопасности](concepts/safety-model.md).
