# 1.7.0rc3 release status

The owner authorized this candidate on 2026-11-08 after Python 3.15 support
merged in PR #693. Preparation is in progress; this RC is not yet published.
Stable 1.6.0 remains recommended and retains the default documentation.

## Scope

Standard GIL-enabled CPython 3.11–3.15, the reviewed compatible native/audit
dependency profile, GigaChat 0.2.4 compatibility and the pinned documentation
bootstrap correction. On Python 3.15, PyYAML 6.0.3 may require a compiler;
see [runtime support](reference/support-policy.md).

The explicit `scalable-relational-v1` engine supports bounded acyclic synthetic
many-to-one/one-to-one relationships, chains, multiple parents and nullable
references. Cycles, composite keys, shared PK/FK identities, global rules and
unsupported generation modes remain rejected. Linux/macOS execution only.
Existing independent engine and source-free defaults remain unchanged.
See [capacity guidance](how-to/dataset-capacity.md).

The development benchmark's four-worker median was 1.953×, below its ≥2×
target and with large variation. It is not a Python 3.15 or release-artifact
speed guarantee. No production data, live database/provider calls, new
source-preserving activation or human dataset approval is granted by release.

## Required acceptance

- Green release PR checks before merge.
- Fresh independent technical AI review of the final exact main SHA.
- Exact-main CI, Containers, Documentation and Security workflows.
- Full local release gate and strict documentation build.
- Ubuntu no-publish preflight and independently verified wheel/sdist hashes.
- Fictional manual MCP client acceptance for the linked-table workflow.
- Accepted-commit binding, signed tag and validated acceptance manifest.
- GitHub/PyPI and signed multi-platform container publication.
- Public package, provenance, container and candidate-documentation verification.

Every item remains subject to recorded evidence. Earlier implementation checks
and historical human acceptance retain their original source/artifact identity.
