# Public Contracts Delta

## Added Requirements

### Requirement: Previous Feature Release Compatibility

The current package SHALL read reviewed specs and generated metadata from the
previous feature-release compatibility baseline.

#### Scenario: A previous reviewed spec is loaded

- **GIVEN** an immutable spec and manifest copied from an annotated release tag
- **WHEN** the current package loads the artifacts
- **THEN** their schema version and fingerprint remain valid
- **AND** deterministic generation produces the expected entity row counts
- **AND** the new bundle remains synthetic and source-row-free

#### Scenario: The baseline advances

- **GIVEN** maintainers select a newer previous-release baseline
- **WHEN** fixtures are added
- **THEN** they are copied into a new versioned directory with tag and commit
  provenance
- **AND** existing baseline files are not regenerated by current models
