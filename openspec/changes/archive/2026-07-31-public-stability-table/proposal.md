# Change: public-stability-table

## Why

External users need one authoritative map of supported, versioned, and
experimental surfaces before the `1.0` compatibility baseline.

## What Changes

- Publish the owner and stability level for every documented public surface.
- Define additive and breaking changes.
- Link each surface to its existing contract gate.

## Impact

This is a documentation contract. It changes no runtime behavior or package
version.
