1.7.0rc1 release status¶

The owner authorized this prerelease on 2026-10-25. Publication and all 12 public acceptance checks completed. Stable 1.6.0 remains the recommended release and documentation default.

Scope¶

The candidate packages the reviewed feedback work since 1.6.0. See the changelog and release procedure. DatasetSpec schema version remains independent of package version. No source rows are reused in synthetic output. No new transformation extension, dataset approval, live database acceptance or live provider acceptance is claimed. The historical Trino 401 and profile-provenance evidence gaps remain open.

  • Green exact-main CI, Containers, Documentation and Security workflows.
  • Fresh independent exact-commit technical AI review with no open release blockers.
  • Ubuntu no-publish preflight, independently checked wheel/sdist hashes.
  • Accepted-commit binding, SSH-signed tag and validated acceptance manifest.
  • GitHub/PyPI and signed multi-platform container publication.
  • Public installed-package, provenance, container and candidate-documentation checks.
