Corrections¶

  • Root agent instructions now distinguish completed finite stable acceptance, published candidate and still-required review of changed activation.
  • MCP permissions no longer describe the completed stable campaign as future.
  • ADR index/open-question register and transformation boundary explicitly identify historical WIP/pre-activation statements and link later source-bound evidence. Unresolved decisions and the separate trust-amendment task remain unresolved.
  • The proposed richer evidence envelope is explicitly unimplemented. Current relationship/constraint confidence is numeric; illustrative medium is not a supported serialized value. The Russian reference carries the same warning.
  • Dependency compatibility names its reviewed lock and exact-source gate instead of an obsolete gate date. All ten documented direct versions match both uv.lock and the machine-readable compatibility policy; no dependency update.
  • Both roadmaps move completed numeric/relational/statistics/CLI and versioned documentation delivery out of the pending list. Historical evidence gaps, capacity and amendment review stay visible. Monthly-date inference, configurable category ceiling and source-row EAV pivot/unpivot remain deferred.

Historical release reports, archived proposals, immutable golden fixtures and legacy deep-link anchors remain intact. Conditional OpenSpec scenarios about an incomplete campaign still describe that condition, not current release status.

  • All 24 documentation-build tests then passed in a separate environment synced from the reviewed lock with docs and dev dependencies. No module remains skipped in this selected scope.
  • Strict MkDocs succeeded with the complete locked docs environment. Preliminary attempts in other existing environments stopped at missing MkDocs/mike before building; they were tooling setup failures, not successful validation.
  • All 29 strict OpenSpec items passed. The template's informational archive note is not a completed product change. Whitespace validation passed.

No new live database/provider call, dataset approval, security scan, private-input replay, UI campaign or target-size capacity run is claimed.
