Installed acceptance¶

The accepted Ubuntu wheel passed 600/600 core routes for each of MCP SDK1 and SDK2, with two seeded runs per route and 200 routes per Python, CLI and real-stdio MCP interface. Same-seed and cross-interface logical/spec/validation/ business-report checks passed; MCP processes were reaped. Database fixtures were fictional stand-ins.

Separate installed option selections passed 644 SDK2 tests and 100 base tests, with zero failures or skips, including all six deadline and three native-profile-bounds regressions. The base environment had no Arrow, DuckDB or MCP. Execution used target Python -I, no PYTHONPATH and a root-only pytest path override. Installed payload/provenance checks ran before/after, without a per-test origin recorder. SDK1 used compatibility-only MCP 1.28.1 and httpx-sse 0.4.3; project dependencies and lockfile were unchanged.

The bounded installed acceptance asset has SHA-256 8f7c3e243f178b0de68c13c8d31db536d8781686667f861dfa6bd235c6f242d5. Core routes and selected options are separate finite scopes, not exhaustive option combinations or new capacity measurements. No live database/provider campaign, new manual human acceptance or dataset approval is claimed.
