Скачать документацию¶

English · Русский

Полная опубликованная сборка содержит:

  • PDF handbook — для чтения, печати и передачи.
  • Автономный HTML — один файл со встроенными assets.
  • Markdown ZIP — исходники, включая русские страницы, справочники и историю.
  • Offline site ZIP — выбранная версия сайта с обоими языками. Распакуйте и запустите python3 -m http.server для локального поиска.

Общий печатный справочник включает пользовательские главы English и Русский по навигации. История, roadmap и административные страницы в него не входят. Это один двуязычный документ, а не два независимо версионируемых перевода.

Version/source пакета, documentation revision и hashes экспортов записываются в documentation.json. Исправление перевода не наследует exact-SHA review пакета. Экспорт документации не читает datasets, credentials или approvals.

Файлы появляются только после полной сборки. Обычный локальный preview содержит combined print page, но не PDF/ZIP. Порядок: публикация документации — English.
