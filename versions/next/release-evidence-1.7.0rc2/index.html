Scope and limits¶

Capacity guidance describes byte/time ranges, explicit budgets and the independent-table scalable engine. Relationships, global rules and unsupported generation modes use the existing bounded path; the new engine rejects them before generation. Scalable execution requires Linux or macOS; native Windows execution of this engine is unsupported in this RC. Memory checks are cooperative, not OS isolation. Timing forecasts cover standalone source-free bundles and exclude attached-source scans and human review. Benchmark evidence retains its measured implementation/environment identity rather than becoming a later release-artifact performance measurement.

No production data, live database/provider execution, source-preserving transformation activation or new human dataset approval is claimed. Stable 1.6.0 retains the default documentation; candidate guides are isolated under versions/1.7.0rc2/.
