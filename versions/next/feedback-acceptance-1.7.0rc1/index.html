Installed feedback acceptance — 1.7.0rc1¶

This dated follow-up binds the original findings 1–26 and section E to actual public installed packages. It supplements the historical client register; no private measurements or prior runs are relabelled. The machine-readable ledger records every selected test case/outcome, fixture hashes, original script hashes and all 61 historical source-anchor locations for each installed package.

Package identity and results¶

Baseline is published 1.6.0, source 258c035c22408becf17ab090635710a50dda8ccc; candidate is published 1.7.0rc1, source 64b7c8c3bbb0174fd7e159c4dfb42312045a1716. Independently downloaded PyPI wheels match the release hashes, and all 157/173 installed package payloads match those wheels byte-for-byte. Both separate Python 3.11.2 environments use MCP 2.3.0, OpenAI 3.37.0, SQLGlot 30.24.0, PyArrow 26.0.0, Pydantic 2.14.1 and Faker 40.43.0 for this comparison. These current dependencies do not reconstruct the historical client environment.

The shared cohort has 782 cases across 32 maintained fictional test modules: 1.6.0 has 757 passes and 25 differing assertions; 1.7.0rc1 passes all 782 after the environment correction below. The 25 differences include new-feature and changed mock-query expectations, so they are not 25 newly discovered baseline bugs. Candidate conditional formulas additionally pass all 33 cases; dependency guards pass on both packages. Twenty real doctor --require-extra parquet --json invocations in fresh processes per package all exit zero.

The initial cohort recorded 756/26 and 781/1 pass/fail respectively: a clean PATH hid pg_config, preventing installed psycopg from loading native libpq. Doctor correctly stopped at dependency import before the expected Trino check. Adding the installed native dependency discovery directory made the unchanged doctor/dependency tests pass (17 per package). The first conditional follow-up also omitted its example file (48 passes, two fixture failures); copying the exact reviewed fictional example produced 33/33. Original outcomes and separate rechecks are retained rather than silently overwritten. Product code was not patched.

Original scripts and disclosed adaptations¶

Six original scripts were run unchanged on each package in new temporary roots: golden_run.py, probe_output_contract.py, probe_doctor_parquet.py (base arm, 20 repeats), rc_anchor_check.py, probe_mode_flags_ab.py and probe_parquet_types_ab.py. The controller bounds each run, selects its CLI explicitly by PATH and clears external configuration. Only their fictional self-contained fixtures are available; no private profiles/specs are supplied.

Both golden runs report six green and three red checks: source-enum copying is intentionally unsupported by default, and the private snapshot/pair are absent. The original script exits zero even with these reds. Each publication run executes 40 fresh processes: 32 successes and eight intended filled-directory rejections; its banner still incorrectly says 1.5.0. The maintained five-case adaptation checks exit, file contents, layout and preservation, not mere file existence. It passes on both actual packages. The original doctor base arm reports 20/20 on each; separate real CLI doctor results are above.

The mode probe treats deliberate invalid publication exit 1 as a failure, passes a nonzero invalid ratio to edge/load modes that forbid it, and compares hashes as if they established semantics. Preserve its diagnostic output; the eight maintained CLI mode cases assert actual settings/artifacts and pass. The Parquet probe inspects both valid and negative arms, then uses the last (negative) file for its round-trip: the resulting string types do not demonstrate valid-mode type loss. Declared valid-mode physical schema/readback tests pass separately.

The Trino ladder script has a Python 3.11 SyntaxError at line 206 and its private query is absent. Its product-monkeypatched arm is not an acceptance route. The publication fix wrapper/runner also monkeypatch production code, so their fixed arms are retained as diagnostic history and excluded from acceptance. Unpatched installed SQL/publication controls above provide the reviewed replacement scenarios. None of these exclusions is counted as a passing original probe.

Tests and their exact fictional example are copied outside the checkout. A legacy src fixture path explicitly points to that arm's installed site-packages; initial imports and subprocess checks verify installed-package provenance. No application source checkout is imported. Reproduction uses the selected interpreter with -I -m pytest, disabled automatic pytest plugins, the listed 32 test modules and TEST_DATA_AGENT_ACCEPTANCE_PACKAGE_ROOT set to installed site-packages. Add the reviewed example for test_conditional_formulas.py. The ledger retains controller, fixture and report hashes and every test case. Parameter payloads are replaced by deterministic per-function case ordinals; fixture hashes bind reconstruction without publishing sensitive-shaped test literals.
