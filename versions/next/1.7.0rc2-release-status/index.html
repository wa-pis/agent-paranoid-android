1.7.0rc2 release status¶

The owner authorized this candidate on 2026-11-08, including a pull request, merge after green checks and release. Publication and all 12 public acceptance checks completed. Stable 1.6.0 remains recommended and retains the default documentation location.

Scope¶

Capacity forecasts for CSV/JSON/Parquet, logical database payload and approximate PostgreSQL heap storage, bounded synthetic timing calibration, and opt-in scalable generation with distinct rows, explicit budgets and up to four workers. Scalable execution in this RC requires Linux or macOS. See capacity guidance and the changelog. Scalable execution supports independent tables; relationships and global rules remain on the existing bounded generation path. Source transformation and database access policies remain unchanged. No live database acceptance is claimed.

Required acceptance¶

  • Green PR checks before merge.
  • Fresh independent exact-main technical AI review with no open release blockers.
  • Exact-main CI, Containers, Documentation and Security workflows.
  • Ubuntu no-publish preflight and independently checked wheel/sdist hashes.
  • Accepted-commit binding, signed tag and validated acceptance manifest.
  • GitHub/PyPI and signed multi-platform container publication.
  • Public installed-package, provenance, container and candidate-documentation checks.

Implementation benchmarks are recorded in the OpenSpec evidence; they are not an assertion of installed release-artifact or human client acceptance.
