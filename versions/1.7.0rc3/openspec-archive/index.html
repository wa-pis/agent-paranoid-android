OpenSpec Archive¶

Completed design changes are retained in the OpenSpec archive. The archive records accepted proposals, designs, tasks, and capability deltas; it is implementation history rather than user documentation.

Current product direction is summarized in the Roadmap. Public behavior is described by the canonical OpenSpec capabilities and the task-oriented documentation site.
