Scope and limits¶

Standard GIL-enabled CPython 3.11–3.15 is supported; PyYAML 6.0.3 may require a compiler on Python 3.15. No free-threaded or alternate-interpreter support, cross-Python byte identity or Python 3.15 speed guarantee is claimed.

The explicit scalable relational engine supports bounded acyclic synthetic many-to-one/one-to-one graphs, chains, multiple parents and nullable links. Cycles, composite keys, shared PK/FK identities, global rules and unsupported modes reject before generation. Linux/macOS execution only; memory checks are cooperative. The development four-worker median was 1.953×, below the ≥2× target and with substantial variation; this is not a release-artifact speed claim. See capacity guidance.

Only fictional fixtures were used. No production data, live database/provider calls, source-preserving activation or new human dataset approval is claimed. Candidate guides remain isolated under versions/1.7.0rc3/; stable 1.6.0 keeps the default documentation.
