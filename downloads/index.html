Downloads¶

English · Русский

Published builds provide:

  • PDF handbook: read, print or share the user guide.
  • Standalone HTML handbook: one file with embedded assets and internal chapter links; detailed references link to the matching version online.
  • Markdown source ZIP: the documentation source tree, including reference and historical pages with their original provenance.
  • Offline site ZIP: the complete selected documentation version. Extract it and run python3 -m http.server to use browser search locally.

Read or print the combined handbook. The handbook follows the user navigation; history, roadmap and documentation administration are excluded. It is assembled by MkDocs' print-site plugin rather than a separate book renderer.

Every download is bound to package version/source and documentation revision. The export manifest records handbook chapters and artifact hashes. Documentation corrections are distinct from package release review. Exporting docs does not export datasets, profiles, credentials or approvals.

Download files appear only after the complete build. A plain local preview has the combined print page; use the full build for PDF, standalone HTML and ZIP files.
