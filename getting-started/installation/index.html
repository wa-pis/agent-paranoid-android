Installation¶

Stable 1.6.0 is the recommended release. Its signed source, packages and containers passed public verification.

Requirements¶

  • Python 3.11 or newer
  • enough local disk space for the requested output
  • a dedicated working directory for inputs and generated artifacts

The supported CI matrix covers CPython 3.11, 3.12, 3.13, and 3.14. Python 3.11 remains the minimum so users can adopt newer interpreters without forcing existing environments to upgrade. The notice and release-gate rules for changing this matrix are defined in Runtime And Integration Support.

Read the migration notes before regenerating existing fixtures.

Install From PyPI¶

The stable release is 1.6.0; the commands below pin that exact version for reproducible installation.

Create an isolated environment:

macOS and Linux¶

python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install --upgrade pip
python3 -m pip install "agent-paranoid-android==1.6.0"

The base package supports CSV, JSON, and deterministic PostgreSQL SQL export. Add only the source and format integrations you need:

python3 -m pip install "agent-paranoid-android[parquet]==1.6.0"
python3 -m pip install "agent-paranoid-android[mcp]==1.6.0"
python3 -m pip install "agent-paranoid-android[mcp,trino]==1.6.0"
python3 -m pip install "agent-paranoid-android[postgres]==1.6.0"
python3 -m pip install "agent-paranoid-android[openai]==1.6.0"
python3 -m pip install "agent-paranoid-android[gigachat]==1.6.0"

Dependency footprint budgets live in Dependency Compatibility.

The all extra remains available for development, demos, and container builds. It is not the recommended user installation. Use test-data-agent doctor --require-extra all to verify that full environment.

The experimental GigaChat adapter is retained in 1.6.0 through its explicit gigachat extra. Follow Use The GigaChat Advisor for authentication, mandatory TLS verification, and the review-first workflow. The default provider remains OpenAI.

Stable 1.6.0 is the recommended default. Add an optional extra to the same exact stable pin only when needed.

Windows PowerShell¶

py -3.11 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install "agent-paranoid-android==1.6.0"

Run the self-contained environment check:

test-data-agent doctor

Expected final lines:

quickstart smoke: ok
doctor passed

doctor uses a temporary fictional fixture and makes no external calls. Use doctor --require-extra parquet (or another installed extra) for an offline capability check. See Troubleshooting for individual checks and CLI automation for JSON output.

For development setup use Contributing. For documentation builds use Publishing Documentation. Shell completion has its own reference.

Confirm The Installed Version¶

python3 -c "import test_data_agent; print(test_data_agent.__version__)"

The package name is agent-paranoid-android. The command remains test-data-agent.
